# CIS 440 Workout Tracker — recruiter case study

This repository is a public, code-free portfolio case study for a beginner-friendly workout planning and tracking application developed as a six-person CIS 440 academic team capstone.

Other contributor names are omitted pending their individual publication preferences. **Jonathan Rodriguez is the public-release maintainer and a verified frontend/routing contributor, not the sole author.** He is identified only for contribution areas supported by the private project history.

Direct team authorization has not yet been obtained. This is not an official publication or endorsement by the full team, the instructor, Arizona State University, or W. P. Carey.

## Verified contribution boundary

Private diff review supports the following bounded contribution areas for Jonathan:

- dashboard and internal-page interface foundations;
- client-side token-presence navigation guard and related routing behavior;
- workout-entry and calendar prototypes;
- responsive workout-catalog grouping, loading, and expansion behavior;
- recovery and repeated-muscle-group reminder heuristics;
- beginner routine planning;
- configurable workout-history analytics and chart views; and
- selected naming, routing, browser-compatibility, and server-startup maintenance.

Architecture, backend services, database work, authentication, testing, design, and other product areas also contain team contributions. This case study does not assign those shared areas to Jonathan unless the private evidence supports the bounded statements above.

## Code-free and privacy boundary

This repository contains no application source, private Git history, environment file, credential, SQL database, real account, workout record, teammate email, or private screenshot. The interface examples and diagrams are synthetic. The separate sanitized source candidate remains local, Git-free, and unpublished throughout Stage 1 pending direct team review and a separate Phase 2 authorization.
